# Судовая документация → Markdown

Скрипт рекурсивно обходит папки и для каждого файла создаёт `.md` в отдельной папке с той же структурой подпапок. Исходные файлы не изменяются. Сканы распознаются автоматически (OCR, русский и английский). Для чертежей и схем создаются карточки.

| Судно | Источник | Результат |
|---|---|---|
| Avacha | `E:\000 Avacha\1. VSLdocuments` | `E:\000 MD\Avacha\...` |
| Chaivo | `E:\000 Chaivo` | `E:\000 MD\Chaivo\...` |

Всё выполняется на этом компьютере, документы никуда не отправляются.

## Запуск

1. Если Python нет, установите Python 3.10 или новее с https://www.python.org и отметьте *Add python.exe to PATH*.
2. **`install.bat`**: запускается один раз.
3. **`convert.bat`**: конвертация. При первом запуске скрипт сам скачает языковые файлы для OCR (несколько десятков МБ).

Процесс можно прервать клавишами Ctrl+C. Повторный `convert.bat` обрабатывает только новые и изменённые файлы, а также то, что в прошлый раз не удалось.

## Что получается

- `E:\000 MD\_INDEX.md`: оглавление со ссылками на все файлы, сгруппированное по судну и папке.
- `E:\000 MD\_report.csv`: отчёт по каждому файлу (открывается в Excel).
- `...\Имя файла.pdf.md`: содержимое документа. В начале файла указаны источник, судно, дата изменения исходника, число страниц и способ конвертации.

| Тип | Как обрабатывается |
|---|---|
| PDF с текстом, Word, Excel, PowerPoint, `.msg`, `.eml`, `.txt`, `.xml`, `.zip` | текст, таблицы, заголовки |
| `.doc`, `.xls`, `.ppt`, `.rtf`, `.xlsb`, `.odt` | через MS Office (если его нет, через LibreOffice), затем как выше |
| PDF-сканы, смешанные PDF, изображения с текстом | OCR постранично |
| Чертежи и схемы | карточка, см. ниже |

## Чертежи и схемы

Чертежом считается:
- файл `.dwg` или `.dxf`;
- PDF, у которого большинство листов формата A2 и крупнее;
- PDF или изображение из папки, в пути которой есть «чертеж», «схем», «drawing», «dwg», «P&ID» или «diagram».

Для каждого чертежа создаётся карточка:
- ссылка на оригинал и предупреждение, что размеры и параметры брать только из оригинала;
- превью первого листа (`.preview.jpg` рядом с `.md`);
- все надписи с чертежа: штамп (номер, название, ревизия), теги арматуры и оборудования, примечания, спецификация. Для сканов надписи распознаются через OCR.

По карточкам чертёж находится поиском по номеру, тегу (например `V-101`) или названию системы. Геометрию и размеры в текст перенести нельзя, поэтому рабочим документом остаётся оригинал.

**DWG.** Чтобы извлечь надписи из `.dwg`, нужен бесплатный ODA File Converter (opendesign.com). Скрипт найдёт его сам. Без него для DWG создаётся карточка без надписей. Если конвертер установить позже, повторный `convert.bat` дообработает только эти файлы.

## Статусы в `_report.csv`

| Статус | Значение |
|---|---|
| `OK` | сконвертировано |
| `OCR` | сконвертировано, сканы распознаны |
| `DRAWING` | карточка чертежа с надписями |
| `DRAWING_NO_TEXT` | карточка DWG без надписей (нет ODA File Converter) |
| `NO_TEXT` | изображение без текста (фото) |
| `UNCHANGED` | не менялось с прошлого запуска |
| `LOW_TEXT`, `NEEDS_OCR` | OCR был недоступен (причина выводится в начале). Повторный запуск дообработает эти файлы |
| `NO_CONVERTER` | `.doc`/`.ppt` без MS Office и без LibreOffice |
| `UNSUPPORTED` | `.rar`, `.7z`, видео, аудио и т.п. |
| `ERROR` | повреждённый файл или файл под паролем (подробности в колонке `message`) |
| `TIMEOUT`, `CRASH` | файл обрабатывался слишком долго или вызвал сбой; остальные файлы обрабатываются дальше |
| `TOO_LARGE` | файл больше 500 МБ |
| `ACCESS` | нет доступа к папке или файлу |

## Учесть при использовании

- Цифры из OCR (давления, номера, даты) сверять с оригиналом. Таблицы на сканах распознаются как текст без табличной структуры. Рукописный текст, печати и подписи не распознаются.
- Вложения писем не конвертируются.
- Если исходник удалён, его старый `.md` остаётся.

## Параметры (необязательно)

```
python vsl_docs_to_md.py --scan                    только посчитать файлы по типам

```
