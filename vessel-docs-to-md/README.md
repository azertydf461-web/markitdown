# Судовая документация → Markdown

Скрипт `vsl_docs_to_md.py` рекурсивно обходит папки с документацией судов и для каждого файла создаёт `.md` в отдельной выходной папке с той же структурой подпапок. Исходные файлы не изменяются.

По умолчанию обрабатываются:

| Судно | Папка-источник | Куда пишется результат |
|---|---|---|
| Avacha | `E:\000 Avacha\1. VSLdocuments` | `E:\000 MD\Avacha\...` |
| Chaivo | `E:\000 Chaivo` (вся папка) | `E:\000 MD\Chaivo\...` |

Пути меняются в начале скрипта (`DEFAULT_SOURCES`, `DEFAULT_OUTPUT`) или параметрами `--source` и `--out`.

**Конфиденциальность:** конвертация и распознавание выполняются на вашем компьютере. Документы никуда не отправляются: нет ни LLM, ни облачных сервисов. Интернет нужен только один раз, чтобы установить пакеты.

## 1. Установка (один раз)

1. **Python 3.10 или новее** с https://www.python.org. При установке отметьте *Add python.exe to PATH*.
2. Запустите **`install.bat`**. Он установит MarkItDown (конвертер от Microsoft), PyMuPDF (анализ PDF и OCR) и pywin32 (для работы через MS Office).
3. **Старые форматы** `.doc`, `.ppt`, `.rtf`, `.xlsb`, `.odt`/`.ods`/`.odp`. Сначала они пересохраняются в `.docx`/`.pptx`/`.xlsx`, затем конвертируются. Скрипт сам использует установленный **MS Office**, а если его нет, то **LibreOffice** (бесплатный, https://www.libreoffice.org). Если нет ни того ни другого, такие файлы получат статус `NO_CONVERTER`.
4. **Распознавание сканов (OCR)** нужно по желанию, но для судовых архивов почти наверняка понадобится: сертификаты, акты и формы класса часто хранятся как сканы. Нужны только языковые файлы Tesseract, сама программа Tesseract не нужна, потому что движок встроен в PyMuPDF.
   - Самый простой способ: запустить **`get_tessdata.bat`**. Он скачает `rus.traineddata` и `eng.traineddata` в папку `tessdata` рядом со скриптом.
   - Если скачивание заблокировано, скачайте эти два файла вручную по ссылкам ниже и положите их в папку `tessdata` рядом со скриптом:
     `https://github.com/tesseract-ocr/tessdata_best/raw/main/rus.traineddata`
     `https://github.com/tesseract-ocr/tessdata_best/raw/main/eng.traineddata`
   - Другой вариант: установить Tesseract (сборка UB Mannheim) и отметить в установщике русский язык. Скрипт найдёт `C:\Program Files\Tesseract-OCR\tessdata` сам.

## 2. Запуск

Порядок работы:

1. **`scan.bat`**: инвентаризация без конвертации. Показывает по каждому судну, сколько файлов каждого типа найдено и как каждый тип будет обработан. Результат сохраняется в `E:\000 MD\_inventory.csv`. С этого стоит начать: сразу видно объём, долю сканов и изображений, а также форматы, которые не поддерживаются.
2. **`convert.bat`**: конвертация без OCR. Выполняется быстро. PDF-сканы при этом только помечаются статусом `LOW_TEXT`.
3. **`convert_ocr.bat`**: повторный запуск с OCR. Уже готовые файлы пропускаются. Обрабатываются только PDF со статусом `LOW_TEXT` и изображения.

Процесс можно прервать клавишами **Ctrl+C**. Готовые `.md` сохраняются, а следующий запуск продолжит с оставшихся файлов.

## 3. Что получается

```
E:\000 MD\
  _INDEX.md          оглавление со ссылками на все .md, сгруппированное по судну и папке
  _report.csv        отчёт по каждому файлу последнего запуска (открывается в Excel)
  _inventory.csv     результат scan.bat
  Avacha\Certificates\Class\IOPP.pdf.md
  Chaivo\Manuals\Boilers\Boiler manual.pdf.md
  ...
```

Имя результата равно исходному имени с добавленным `.md`, например `Отчёт.pdf.md`. Поэтому `Отчёт.pdf` и `Отчёт.docx` из одной папки не перезапишут друг друга.

В начале каждого `.md` есть служебный блок: он пригодится для поиска, фильтрации и загрузки в базу знаний.

```yaml
---
source: 'E:\000 Avacha\1. VSLdocuments\Certificates\Class\IOPP.pdf'
vessel: 'Avacha'
relative_path: 'Certificates\Class\IOPP.pdf'
size_kb: 812
modified: '2024-03-11 09:40'
converted: '2026-09-25 10:15'
method: 'markitdown + OCR'
pages: 4
status: 'ocr'
note: 'OCR стр. 2-4 из 4'
---
```

### Статусы в `_report.csv` и в итоговой сводке

| Статус | Что означает | Что делать |
|---|---|---|
| `OK` | сконвертировано | — |
| `OCR` | сконвертировано, сканы распознаны | цифры (давления, номера, даты) сверять с оригиналом |
| `LOW_TEXT` | в PDF есть страницы-сканы без текста | запустить `convert_ocr.bat` |
| `NEEDS_OCR` | изображение (jpg/png/tif), без OCR не обрабатывается | запустить `convert_ocr.bat` |
| `NO_TEXT` | на изображении не найден текст (фото) | — |
| `UNCHANGED` | уже сконвертировано, исходник не менялся | — |
| `NO_CONVERTER` | `.doc`/`.ppt`/`.rtf` без MS Office и без LibreOffice | установить LibreOffice |
| `UNSUPPORTED` | формат не поддерживается (`.dwg`, `.rar`, `.7z`, видео и т.п.) | при необходимости обработать отдельно |
| `TOO_LARGE` | файл больше `--max-size-mb` (500 МБ) | увеличить лимит |
| `ERROR` | ошибка конвертации (текст ошибки в колонке `message`) | чаще всего это повреждённый файл или файл под паролем |
| `TIMEOUT` | не уложился в `--timeout` (30 мин) | увеличить `--timeout` для больших сканов |
| `CRASH` | конвертер аварийно завершился на этом файле | проверить файл вручную |
| `ACCESS` | нет доступа к папке или файлу | проверить права |

## 4. Параметры

```
python vsl_docs_to_md.py [параметры]

  --scan                 только инвентаризация
  --ocr                  распознавать сканы (язык rus+eng, 300 dpi)
  --source ИМЯ=ПУТЬ      своя папка-источник, можно несколько раз (заменяет папки по умолчанию)
  --out ПУТЬ             выходная папка (по умолчанию E:\000 MD)
  --workers N            параллельных процессов (по умолчанию до 4)
  --timeout СЕК          лимит на один файл (по умолчанию 1800)
  --legacy auto|office|libreoffice|off   чем пересохранять старые форматы
  --tessdata ПУТЬ        папка с rus/eng.traineddata
  --ocr-dpi 300          разрешение для OCR
  --min-chars 30         страница PDF с картинкой и меньшим числом символов считается сканом
  --force                переконвертировать всё заново
```

Пример: только ЧАЙВО, результат на диск D:

```
python vsl_docs_to_md.py --source "Chaivo=E:\000 Chaivo" --out "D:\MD" --ocr
```

## 5. Ограничения

- **Качество OCR.** Печатный текст на нормальных сканах распознаётся хорошо. Таблицы из сканов превращаются в текст без табличной структуры. Рукописные записи, печати и подписи не распознаются. Числовые параметры из OCR-текста перед использованием в расчётах или письмах нужно сверять с оригиналом.
- **Скорость OCR:** порядка нескольких секунд на страницу на один процесс. Это оценка по тестовому прогону, фактическое время зависит от компьютера. Толстый скан-мануал на сотни страниц может занять десятки минут. Для таких файлов может понадобиться увеличить `--timeout`.
- **Чертежи** `.dwg`/`.dxf`, архивы `.rar`/`.7z`, видео и аудио не конвертируются. Все такие файлы перечислены в отчёте.
- **Письма.** Для `.msg` и `.eml` конвертируются заголовки и текст письма. Вложения не конвертируются, у `.eml` приводится только список их имён.
- **ZIP.** Содержимое архива попадает в один `.md`, сканы внутри архива без OCR.
- **Файлы под паролем** получают статус `ERROR`. Office не останавливается диалогом ввода пароля.
- **Удалённые исходники.** Если файл удалён из источника, его старый `.md` остаётся в выходной папке.
- При статусе `TIMEOUT` во время работы через MS Office в фоне может остаться скрытый процесс `WINWORD.EXE` или `EXCEL.EXE`. После прогона его стоит закрыть в Диспетчере задач.
- Макросы в документах не запускаются: для MS Office принудительно отключается автоматизация.
- Длинные пути длиннее 260 символов поддерживаются.
